# NEXUS: Beyond the Grid

A cosmic tic-tac-toe game: Classic, AI Challenge (3x3 to 7x7), Chaos Grid, Ultimate and Local Tournament.

Single static file (`index.html`), no build step, no backend. Settings, stats and history are saved in the browser's localStorage.

## Run locally
Open `index.html` in a browser, or run `npx serve .`

## Deploy
Import the GitHub repo in Vercel (Framework Preset: Other, no build command, output directory: root).
